# Nicolas OSBORNE

# Applications en temps réel - TP Application de Post-It sécurisé

## Contexte

Ce TP est réalisé dans le cadre du module "Applications en Temps Réel" en M2 Ingénierie du Web à l'ESGI, dispensé par Laurent BELLON.

## Objectif du TP

L'objectif de ce TP est de développer une application de tableau de bord collaboratif ("Post-It" virtuel), où plusieurs utilisateurs peuvent ajouter, modifier et supprimer des notes en temps réel.
L'objectif est aussi de mettre en oeuvre des mécanismes d'authentification et d'autorisation pour sécuriser l'accès aux fonctionnalités d'écriture et de garantir la propriété des données dans une application temps réel.

## Technologies utilisées

- Node.js et Express
- Socket.IO
- HTML, CSS et Vanilla JS
- JWT (JSON Web Token)

## Lancer l'application

- Installer les dépendances :

```bash
npm install
```

- Lancer l'application :

```bash
node index.js
```

- Accéder à l'application à l'addresse http://localhost:3000
